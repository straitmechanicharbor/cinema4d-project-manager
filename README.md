## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Scene Library** | Organize C4D scenes with client, deadline and render status |
| **Asset Tracker** | Track external textures and assets linked in your C4D scenes |
| **Render Notes** | Log render settings and farm submission info per project |
| **Plugin Config** | Document plugin and preset configurations for project setups |
